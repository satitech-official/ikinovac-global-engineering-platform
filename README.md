# IKINOVAC GLOBAL

Responsive premium engineering landing website built with plain HTML, CSS and JavaScript — no TypeScript or build tooling required.

## Run

Open `index.html` in a browser, or start a local server in this folder:

```powershell
python -m http.server 8080
```

Then visit `http://localhost:8080`.

## Included functionality

- Responsive navigation and mobile menu
- Command palette (`Ctrl`/`Cmd` + `K`)
- Product filters and RFQ basket
- RFQ form validation with locally saved submitted draft/reference
- Smooth scrolling, progressive header, hover states and reduced-motion support

## Image sources

The public-facing industrial photographs are live Unsplash image URLs found through web image search. They include refinery, offshore, power-generation, industrial piping and global logistics scenes. The supplied `assets/ikinovac-logo.jpeg` is the IKINOVAC GLOBAL logo provided by the client.
